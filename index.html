zestjq-css Demo

Client-side demos of zest (CSS selector engine) and zestjq (jq JSON-filter language), integrated to query JSON-valued attributes in live Wikipedia articles.
To use these tools in your own project, see the zestjq-css package README.
(See also mgdm/htmlq which is a similar but orthogonal idea.)
